Relatório técnico em português (pt-BR), para o dono do produto PixelPress (clone do wordbee.com.br), sobre o estado do clone e o que falta para funcionar como o original.

Conteúdo obrigatório (baseado na auditoria real feita):

1. Página de abertura / sumário executivo: o clone é 100% front-end (HTML/CSS/JS) com banco simulado em localStorage (chave pixelpress_clone_db_v1). 13 páginas: index, login, signup, forgot-password, dashboard, criar-artigo, linhas-de-producao, feeds-rss, historico, sites-wordpress, chaves-de-api, planos, perfil. Identidade visual nova PixelPress (amarelo #F5B400 / #FFC61A sobre quase-preto), ícone e logotipo fornecidos pelo cliente.

2. Tabela "o que já funciona": os 11 fluxos testados automatizados com Playwright, todos passando, zero erros de console: login com demo, senha errada (toast "Email ou senha inválidos."), redirect de rota protegida com callbackUrl, signup criando conta e indo ao dashboard, gerar artigo, criar linha de produção, criar feed RSS, busca no histórico, adicionar site WordPress (respeitando limite do plano), gerar chave de API, trocar de plano, salvar perfil, logout.

3. Tabela "o que não funciona de verdade", por função: autenticação (senha em texto claro, sem hash, sem sessão de servidor, sem envio de e-mail no esqueceu-a-senha, sem verificação de e-mail, sem 2FA); criação de artigo (texto por template local, não LLM; imagem é placeholder CSS; nada é publicado no WordPress; sem contagem real de tokens/custo); linhas de produção (sem agendador, cron nunca dispara, sem histórico de execuções); feeds RSS (busca manual inventa itens, sem parser real, sem deduplicação); sites WordPress (teste de conexão é setTimeout, sem /wp-json/wp/v2/posts, credenciais no navegador); chaves de API (chave aleatória local, endpoint curl não existe); planos e cobrança (troca de plano é campo local, sem Mercado Pago, sem webhook, sem fatura real); multi-tenant (dados por navegador, sem backup, sem LGPD).

4. Lista de construção do backend, em 9 fases numeradas com entregáveis concretos: Fase 0 Fundação (Next.js App Router + TypeScript + PostgreSQL Supabase/Neon + Prisma/Drizzle; schema com users, sessions, plans, subscriptions, sites, articles, pipelines, pipeline_runs, feeds, feed_items, api_keys, ai_keys, invoices, usage_counters, audit_log; Auth.js com Argon2id; org_id + RLS; AES-256-GCM para segredos; Sentry + pino). Fase 1 Login real (rotas signup/login/logout/forgot/reset, cookie httpOnly, rate limit Upstash, Turnstile, middleware). Fase 2 Sites WordPress (validação via /wp-json/wp/v2/users/me com Application Password, test real, publish, media, fila BullMQ com retry). Fase 3 Geração de artigos (job: outline, 3 títulos, corpo markdown, SEO meta/slug/keywords, imagem DALL·E/Flux/SDXL, upload no WP; provedores OpenAI/Anthropic/Gemini plugáveis; status SSE/polling; deduplicação por embeddings; usage_counters no servidor). Fase 4 Linhas de produção (CRUD, run, cron repeatable, pipeline_runs, idempotência). Fase 5 Feeds RSS (rss-parser, worker 30 min, dedupe por GUID/link, filtro de palavras-chave). Fase 6 Chaves de API públicas (pp_live_, hash SHA-256, middleware com escopo e rate limit, /v1/articles, OpenAPI, webhooks HMAC). Fase 7 Planos e cobrança (Mercado Pago assinatura, webhook, invoices, enforcement de limites FREE/SIMPLE/BASIC/PRO/ADVANCED, trial, cupom). Fase 8 Perfil/LGPD (PATCH/DELETE /api/me, export JSON, 2FA TOTP, backup). Fase 9 Qualidade (Vitest, Playwright reaproveitando e2e.cjs, k6, CI/CD, métricas).

5. Seção de migração: trocar assets/store.js por assets/api.js com a mesma interface (WB.list, WB.add…) para as telas não mudarem; seed do banco substitui o seed demo; feature flag por página.

6. Cronograma/estimativa em tabela: Fase 0 1–2 semanas, Fase 1 3–5 dias, Fase 2 1 semana, Fase 3 1–2 semanas, Fase 4 1 semana, Fase 5 4–5 dias, Fase 6 4–5 dias, Fase 7 1–2 semanas, Fase 8 1 semana; total ~12 semanas com um dev sênior full-stack até produção com cobrança ativa.

7. Fechamento com as 3 decisões que o cliente precisa tomar antes de começar: provedor de LLM/imagem principal, gateway de pagamento (Mercado Pago vs Pagar.me vs Stripe) e onde hospedar (Vercel + Neon vs VPS própria).

Não invente dados, métricas de mercado, nomes de pessoas nem preços além dos que constam acima. Use os preços dos planos apenas como referência: SIMPLE R$ 29,90, BASIC R$ 49,90, PRO R$ 89,90, ADVANCED R$ 109,90.
